omaloop

open in omaloop

This page renders the loop in your browser with the same synthesis as the desktop engine, using the tone the sender's theme gave it. On Omarchy, "open in omaloop" loads it into your own panel, where your theme picks the sound and key.

Don't have it yet? omaloop is a drop-down groovebox for Omarchy 4.

omarchy plugin add https://github.com/joshuaswarren/omaloop --enable
~/.config/omarchy/plugins/io.github.joshuaswarren.omaloop/install.sh --bind
